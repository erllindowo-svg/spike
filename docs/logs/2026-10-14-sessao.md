## 18. Técnica: chamar uma server action pelo terminal

Útil para suporte e testes manuais sem navegador:

1. Abrir a página uma vez (o Next compila e gera o manifesto).
2. Pegar o ID da action em
   `.next/dev/server/app/(app)/<rota>/page/server-reference-manifest.json`.
3. `curl -X POST http://localhost:3000/<rota> -H "Next-Action: <id>"
-H "Content-Type: text/plain;charset=UTF-8" --data '[<argumentos em JSON>]'`.
4. A resposta é um payload RSC; o resultado da action está na linha `1:`.

Os IDs mudam quando o código muda. O mesmo vale para qualquer pessoa que
alcance o servidor, por isso cada action valida tudo de novo.
